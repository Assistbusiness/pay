Put the official app icons in this folder with EXACTLY these names (square PNG works best):

    gpay.png         Google Pay
    phonepe.png      PhonePe
    paytm.png        Paytm
    whatsapp.png     WhatsApp
    supermoney.png   super.money
    bhim.png         BHIM
    amazonpay.png    Amazon Pay
    cred.png         CRED

- Download each from the company's official brand / press page.
- Missing file = that button shows the app's initials instead (still works).
- Upload this whole "icons" folder to GitHub with index.html.

Add / remove apps: in index.html, find "apps: [" in the CONFIG block and add or delete a line.
  key      = icon file name (without .png)
  android  = package name, from the Play Store link: play.google.com/store/apps/details?id=PACKAGE
  ios      = the app's link scheme (leave "" if unknown – the button then gives a helpful message)
